# Semaphore AI

Веб-приложение для распознавания букв русской семафорной азбуки по положению рук. Анализ позы выполняется в браузере с помощью MediaPipe Pose.

## Возможности

- распознавание семафорных знаков с камеры в реальном времени;
- последовательная сборка букв в текст;
- ручное редактирование результата;
- режим тренировки по заданным словам;
- адаптивный интерфейс для компьютера и телефона;
- локальная обработка видеопотока без отправки изображения на сервер.

## Локальный запуск

Камера доступна на `localhost` или при защищенном HTTPS-соединении. Запустите локальный сервер из корня проекта:

```bash
python -m http.server 8000
```

Затем откройте [http://localhost:8000](http://localhost:8000) и разрешите браузеру доступ к камере.

## Публикация

Проект не требует сборки и готов к публикации через GitHub Pages из корня ветки `main`. Docker для запуска не требуется.
