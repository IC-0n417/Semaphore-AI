# Артек · Семафор

Браузерный тренажёр показа и чтения русской флажной азбуки. Распознавание положения рук выполняется с помощью MediaPipe Pose непосредственно на устройстве пользователя.

## Возможности

- распознавание семафорных знаков с камеры;
- отображение углов рук и настройка допуска распознавания;
- тренировка показа слов по буквам;
- режим чтения семафорных сигналов;
- профиль участника, XP, статистика и локальный рейтинг лагерей;
- экспорт результатов в JSON;
- адаптивный интерфейс для компьютеров и телефонов.

## Локальный запуск

Доступ к камере работает на `localhost` или через HTTPS. Запустите сервер из корня проекта:

```bash
python -m http.server 8000
```

Откройте [http://localhost:8000](http://localhost:8000) и разрешите доступ к камере.

Проект не требует сборки и готов к публикации через GitHub Pages.
